FAQ · THE DETAILS

Good questions.
Straight answers.

What TRAPPUNK can do, what it cannot do, and what you actually need to build one. Select any question to expand the answer.

01Why not just make a mobile phone app?

A mobile app is possible, but it is not automatically a better trainer. Some Android phones have no gyroscope, and sensor performance, screen size and grip vary between devices. A phone held in the hands also feels different from a dedicated training stock. TRAPPUNK uses one known ESP32-S3 board, so we can focus on consistent motion control and touchscreen shooting. A phone version may be explored later.

02How do I know whether my Android or iPhone has a gyroscope?

Check the exact model’s published sensor specifications for gyroscope, or use a trusted sensor-information app to see whether angular-velocity readings are available. Do not confuse a gyroscope with an accelerometer or compass. Many modern phones do have a gyro, especially iPhones, but not every Android model does. Having one still does not guarantee that TRAPPUNK firmware can run on the phone: it is designed for an ESP32 board.

03What do I need to build TRAPPUNK, and how much does it cost?

The supported core is a Waveshare ESP32-S3 Touch LCD 3.49B, hardware V2 (Rev1.1), with the built-in QMI8658 motion sensor. You also need power and a holder or stock. Shots are fired by tapping the touchscreen, so there is no separate trigger button to buy or wire. The board price varies by seller; allow roughly €20–35 for the board alone, plus parts and shipping. Ask the seller explicitly to confirm V2/Rev1.1 before ordering. See BUILD.

04Can someone with no programming experience install it?

Yes. The INSTALL page provides a USB browser installer for the supported V2 board. Use a desktop Chrome or Edge browser, a USB-C data cable and select the connected port when prompted. You do not need PlatformIO or coding knowledge. The installer detects the ESP32-S3 chip, but cannot automatically prove that the Waveshare board is V2. Confirm the revision before flashing.

05Do I need Wi-Fi, a PC or an SD card to practise?

No PC, Wi-Fi or cloud account is required for ordinary standalone practice after the firmware is installed. A computer and USB connection are used for browser installation and certain data-analysis workflows. A microSD card is optional for saving or exporting supported training data. The exact available export features depend on the firmware version.

06Is it a real gun, and does it fire anything?

No. It is a non-firing electronic shooting simulator: a display, motion sensor and touchscreen shot control. There is no projectile, cartridge or shot charge. A simple dedicated wooden or cardboard stock is sufficient for the DIY design. Never handle or attach the device to a loaded firearm.

07How realistic are the clay flights and HIT/MISS results?

TRAPPUNK simulates clay trajectories, gun orientation and virtual shot timing using a mathematical model. That can be useful for structured practice, but it is not a certified measurement of real-world hit probability. The clay aerodynamics, shot model and transfer to actual range performance have not been independently validated. Treat virtual scores as simulator scores, not as proof of competition accuracy.

08What exactly does TRAP COACH analyse?

Depending on the recorded session, TRAP COACH can display target and device-motion traces, movement onset, the time from visible clay to the first shot, first/second-shot timing and virtual hit/miss events. These are measurements within the simulator and its sensors. COACH cannot directly measure your eye movements, finger pressure on the screen, real barrel path or live-range accuracy. Explore COACH.

09Will reinstalling the firmware delete my results?

It can. Browser installation or recovery may erase flash memory, stored session records and settings. Export important results to the supported SD/COACH formats and keep an independent copy before flashing. Do not assume that a successful firmware install is a non-destructive update. Read the install warnings.

10Is TRAPPUNK open source? Can I help improve it?

The website repository and the Coach RAG knowledge base are public. The main firmware source repository is still private; a public BIN download does not make that source open source or grant an MIT licence. You can already report bugs, suggest ideas and share experiments in GitHub Discussions.
