INSTALL · V2 ONLY

Connect USB.
Install TRAPPUNK.

For the Waveshare ESP32-S3 Touch LCD 3.49B V2 (Rev1.1). No coding tools or terminal commands required. Use a desktop computer with Chrome or Edge and a USB-C data cable.

Release candidate · TRAP12 · firmware 0.1.0-trap12-3bb0736a

First-install / recovery release. The image has passed GitHub compilation and integrity checks, but its first browser installation on a separate new V2 board has not yet been verified. Flashing may erase existing training records, settings and Wi-Fi configuration. Back up anything important.

STEP 01 · VERIFY HARDWARE

Your board must be V2.

Supported: Waveshare ESP32-S3 Touch LCD 3.49B V2 (Rev1.1), 640 × 172, with QMI8658 motion sensor.

Before buying, ask the seller: “Is this the V2 (Rev1.1) hardware revision of the Waveshare ESP32-S3 Touch LCD 3.49B?”

Model suffix 3.49B identifies the case, not the hardware revision. V1 is not supported by this release.

QUICK START

Three steps from box to first series

Get the correct V2 board

Ask the seller to confirm V2 / Rev1.1. Older boards are not supported at this stage.

Connect it to your computer

Open this page in Chrome or Edge on Windows, macOS or Linux, and use a USB data cable. Select the correct USB/serial port when prompted.

Install and test

After flashing, disconnect and reconnect if needed. Check screen, touch, QMI8658 motion and a full 25-target session. Report problems in Discussions.

Advanced downloads

For technical users, the factory installation contains four binary files at different flash offsets. Do not flash `firmware.bin` alone at address 0.
