INSTALL · V2 ONLY

USB cable.
One install button.

TRAPPUNK works with the Waveshare ESP32-S3 Touch LCD 3.49B V2 (Rev1.1). Use a desktop Chrome or Edge browser and a USB-C data cable.

Install TRAPPUNK

Connect your V2 board to the computer and confirm the model below.

USB installation is not supported here. Use Chrome or Edge on a computer. Connect through HTTPS and allow USB access in the browser.

Select V2 to enable installation.

Before flashing: Save important results. Installation may erase stored data. The installer will ask for confirmation if erasing is required.

After “Installation complete!” close the installer with × and use your ESP32. The “Install TRAPPUNK” item shown afterward is only for reinstalling; it is not another required step.

Buying a board? Ask the seller to confirm V2 (Rev1.1). Need help? TRAPPUNK Discussions.
