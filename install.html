TRAPPUNK.
Built for V2.

TRAPPUNK works with the Waveshare ESP32-S3 Touch LCD 3.49B V2 (Rev1.1). For further information, use the project Discussions.

TRAPPUNK for Waveshare V2

Interested in trying the simulator? Visit TRAPPUNK Discussions to ask about the project and supported hardware.

Important: Keep the board still when powering on. Before switching on the ESP32, place it on a stable, level surface. Hold the power button as required, then release it without lifting or moving the board. The gyroscope calibrates during startup. Leave it motionless until the normal TRAPPUNK screen appears; the START image alone does not mean calibration has finished. Allow roughly 10–15 seconds. If it is still showing START after about 30 seconds, switch it off and restart on a stable surface. If the problem repeats, report it in Discussions.

Buying a board? Ask the seller to confirm V2 (Rev1.1). Need help? TRAPPUNK Discussions.
